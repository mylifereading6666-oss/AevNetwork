AevNetwork 使い方ガイド

最終更新日：2026年11月14日

AevNetworkは、ゲームを楽しむ利用者向けのコミュニティ・情報サービスです。AevToolsと共通のアカウント・プロフィール基盤を利用します。

はじめ方メニュープロフィール掲示板フレンドチーム管理・通報注意事項

1. はじめ方

  1. AevNetworkのトップページを開きます。
  2. アカウントページからAevToolsと共通のメールアドレス・パスワードでログインします。
  3. 左上の三本線メニューから各機能を選択します。
  4. ログインが必要な機能では、画面にログイン案内が表示されます。

2. メニュー・情報ページ

  • ホーム：サービスの入口と公開お知らせ。
  • お知らせ：運営からの重要情報。
  • AevNews：運営が掲載するニュース。
  • アップデート情報：機能追加・修正等の更新履歴。
  • 掲示板：利用者が投稿・コメントを行う交流機能。
  • フレンド：ユーザー検索、フレンド申請、承認・拒否、解除。
  • プロフィール：自分や他ユーザーの公開プロフィールを表示。
  • チーム：チーム作成、参加申請、招待、承認、チーム内チャット等。利用可能な操作は画面に表示されます。

3. プロフィールの編集・画像アップロード

  1. アカウントページを開いてログインします。
  2. プロフィール設定の編集画面を開きます。
  3. アイコン・バナーのファイル選択から画像を選び、アップロードボタンを押します。
  4. JPEG、PNG、WebP、GIFに対応し、1ファイル最大5MBです。
  5. アップロード成功後、プロフィール設定の保存ボタンを押します。

プロフィールはAevToolsと共通です。画像や自己紹介等は公開される場合があります。画像を変更できるのはプロフィール本人のみで、管理者も他人のプロフィール画像を変更できません。

4. 掲示板の使い方

  1. 掲示板ページを開き、ログインします。
  2. 投稿フォームに内容を入力し、必要に応じて画像を添付して送信します。
  3. 他の利用者の投稿にコメントできます。
  4. 自分の投稿・コメントは画面上の削除操作で削除できます。投稿後の編集が提供されない場合は、送信前に内容を確認してください。
  5. 不適切な投稿は報告機能から理由を添えて報告します。

画像の対応形式・容量は投稿画面の表示に従ってください。第三者の著作物、個人情報、嫌がらせ等を投稿しないでください。

5. フレンド機能

  1. フレンドページでユーザー名等を検索します。
  2. 対象ユーザーにフレンド申請を送信します。
  3. 相手が承認するとフレンドになります。届いた申請は承認または拒否できます。
  4. フレンド解除は対象ユーザーの操作欄から行います。

相手が望まない申請を繰り返したり、フレンド機能を嫌がらせに利用したりしないでください。

6. チーム・招待・チャット

  • チーム機能の作成・参加・招待・承認等は、各画面の案内に従ってください。
  • 通常のチーム定員は最大4名です。定員に達した場合、新しい招待コードを発行できない場合があります。
  • 管理者による追加参加は、監査または利用者からの仲介依頼等、定められた条件下に限られます。管理者操作は監査記録に残ります。
  • チームチャットは参加者に表示されます。管理者による監査閲覧・仲介は、権限と依頼状態に応じて行われます。
  • 招待コードやチーム情報を無関係な第三者に公開しないでください。

7. 通報・運営対応

掲示板等の報告機能から問題を報告できます。管理者は内容を確認し、必要に応じて投稿削除、理由通知、機能制限、AevNetwork内ブラックリスト等の対応を行います。ブラックリストはAevNetworkの対象機能に適用され、共通アカウント全体を自動停止するものではありません。サポート窓口では運営への問い合わせを送信できます。依頼を取り消す場合は画面に表示される理由を入力してください。

8. 注意事項・トラブル対応

  • オンライン機能の利用にはインターネット接続と有効なログイン状態が必要です。
  • 保存・同期に失敗した場合は、通信状態とログイン状態を確認し、時間をおいて再度操作してください。
  • 公開プロフィール・掲示板はログインしていない人にも見える場合があります。個人情報を公開しないでください。
  • 他人の画像・文章を許可なく使用しないでください。
  • 認証情報・招待コードを他人に渡さず、共用端末ではログアウトしてください。
